# ADR-004：工作区级壁纸库与本地缓存

- Status: accepted
- Date: 2026-08-11

## 背景

原有看板背景作为项目附件保存，只能由单个项目引用。用户需要一次上传后供所有项目选择，
并允许项目在多张壁纸中按间隔随机轮播。若轮播直接读取 WebDAV，会产生不必要的流量且离线不可用。

## 决策

- 壁纸元数据作为 `SharedContent.wallpapers` 保存到 `shared_content.json`，参与现有三路合并。
- 壁纸二进制保存在工作区根级 `wallpapers/`，与项目 `attachments/` 分离。
- WebDAV 同步时按壁纸库引用集合上传、下载并清理孤儿文件；下载文件持久化在本地同名目录。
- 项目设置只保存壁纸 id、播放方式与切换间隔，不复制图片二进制。
- 轮播计时和当前随机下标属于运行时本地状态，不写入同步数据，也不会触发网络请求。
- 删除壁纸库条目时，同时清理所有项目设置中的对应引用，避免悬空引用。
- 旧版 `backgroundAttachmentId` 项目附件继续兼容读取；新上传统一进入工作区壁纸库。

## 结果

- 同一壁纸只需在每台设备缓存一份，所有项目可复用。
- 离线时只要本地缓存存在，预览与轮播均可继续工作。
- 新客户端需要同时检查共享内容序列化、三路合并、根级媒体同步和项目设置兼容默认值。
