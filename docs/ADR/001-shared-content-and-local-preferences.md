# ADR-001：同步用户内容，保留设备偏好

- Status: accepted
- Date: 2026-08-03

## 背景 

应用以个人多设备使用为目标。现有卡片标签只同步 key，自定义标签定义却仅存本机，已经导致跨设备显示不完整。后续保存视图、模板和活动历史也需要明确所有权。

## 决策

用户创建且影响任务含义的内容通过 WebDAV 同步：

- 自定义标签及标签回收站
- 保存视图
- 模板
- 活动历史
- WIP 配置
- 卡片提醒与重复规则

设备相关内容仅保存在本机：

- WebDAV 凭据
- 当前项目
- 明暗模式、拖拽延迟和引导状态
- 撤销栈和通知调度记录
- SyncBase

共享数据沿用 JSON、SyncBase 和三路合并，不引入账号服务或 CRDT。

## 结果

- Windows 与 Android 对任务含义保持一致。
- 新增同步实体必须提供向后兼容的默认值、合并策略和冲突解决入口。
- 界面需要明确区分“跨设备内容”和“仅本机偏好”。
