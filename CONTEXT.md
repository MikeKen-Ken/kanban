# Domain vocabulary

- **Workspace**: the complete user-content set needed for one sync, including the project list, project data, and app-level shared data.
- **Project**: an independent board plus its settings, trash, templates, saved views, and activity history.
- **Board**: the ordered set of columns inside a project.
- **Column**: a workflow stage that holds cards; may configure sort, pinning, and WIP limits.
- **Card**: a task entity with title, notes, status, dates, priority, labels, subtasks, and attachments.
- **Done Column**: the completion stage named in project settings. Checking a card complete moves it into this column.
- **Calendar View**: browse and adjust unfinished cards across projects by due date; selecting a day shows that day's tasks at the bottom (including today). MCP `today_cards` still provides overdue / today / this-week aggregate queries.
- **Saved View**: a named, synced combination of filters.
- **Quick Capture**: an entry point to create cards without entering a specific column.
- **Recurrence Series**: a set of cards generated by the same recurrence rule; series id and period key are used for multi-device idempotence.
- **Reminder**: the combination of a synced reminder time and device-local system notification scheduling.
- **WIP limit**: a suggested maximum of unfinished cards in a column. The current product uses a soft limit: warn and highlight, do not block the action.
- **Template**: a reusable set of card fields, not including image binaries.
- **Activity Event**: an append-only, immutable user-action record inside a project.
- **Trash**: a recoverable deletion snapshot; both ordinary deletes and conflict-confirmed deletes should enter trash.
- **SyncBase**: the device-local snapshot of the last successfully merged workspace, used for local/base/remote three-way merge.
- **Conflict**: both sides' results kept when the same field or a delete-vs-edit intent cannot be merged automatically.
- **Shared Data**: user content that spans projects and syncs over WebDAV, such as custom labels.
- **Local Preferences**: UI and device settings that do not participate in WebDAV sync.
